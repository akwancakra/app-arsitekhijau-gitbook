# Overview Kalendar

Modul **Kalendar** (Calendar) menampilkan hari-hari penting seperti libur nasional, cuti bersama, dan jadwal kerja.

## Cara Melihat

1. Dari **Dashboard**, tap icon **📅 Kalendar**
2. Lihat tampilan kalendar bulanan

![Tampilan Kalendar](.assets/images/hrm-mobile/calendar/tampilan-kalendar.png)

## Event yang Ditampilkan

| Jenis Event | Warna / Tanda |
|---|---|
| **Libur Nasional** | Merah |
| **Cuti Bersama** | Oranye |
| **Jadwal Kerja** | Biru (jika ada jadwal khusus) |
| **Hari Libur Akhir Pekan** | Abu-abu |

## Detail Event

Tap pada tanggal tertentu untuk melihat event di hari itu:

![Detail Event](.assets/images/hrm-mobile/calendar/detail-event.png)

Menampilkan:
- Nama event / keterangan
- Tanggal
- Tipe event

> **Catatan:** Kalendar bersifat read-only. Kamu tidak bisa menambahkan event sendiri.
