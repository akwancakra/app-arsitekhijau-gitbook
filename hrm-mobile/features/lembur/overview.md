# Overview Lembur

Modul **Lembur** (Overtime) memungkinkan kamu mengajukan kerja lembur dan mengelola persetujuannya.

{% hint style="info" %}
Terdapat dua tipe lembur: **Lembur Hari Kerja** (Workday Overtime) untuk lembur di hari kerja biasa, dan **Lembur Hari Libur** (Holiday Overtime) untuk lembur di hari libur atau akhir pekan. Perhitungan kompensasi keduanya bisa berbeda sesuai kebijakan perusahaan.
{% endhint %}

## Fitur yang Tersedia

{% table data-view="cards" %}
| Fitur | Deskripsi |
| --- | --- |
| **Pengajuan Lembur** | Membuat request lembur baru dengan form tipe, tanggal, dan jam |
| **Approval Lembur** | (Khusus approver) Setujui atau tolak pengajuan lembur bawahan |
{% /table %}

## Tipe Lembur

| Tipe | Keterangan |
|---|---|
| **Lembur Hari Kerja** (Workday Overtime) | Lembur di hari kerja biasa (Senin - Jumat) |
| **Lembur Hari Libur** (Holiday Overtime) | Lembur di hari libur / akhir pekan |
