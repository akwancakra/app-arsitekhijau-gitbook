# Overview Lembur

Modul **Lembur** (Overtime) memungkinkan kamu mengajukan kerja lembur dan mengelola persetujuannya.

## Tipe Lembur

| Tipe | Keterangan |
|---|---|
| **Lembur Hari Kerja** (Workday Overtime) | Lembur di hari kerja biasa (Senin - Jumat) |
| **Lembur Hari Libur** (Holiday Overtime) | Lembur di hari libur / akhir pekan |

## Fitur yang Tersedia

| Fitur | Deskripsi |
|---|---|
| **Pengajuan Lembur** | Membuat request lembur baru |
| **Riwayat Lembur** | Daftar pengajuan lembur (pending/approved/rejected) |
| **Approval Lembur** | (Khusus approver) Setujui/tolak lembur bawahan |
