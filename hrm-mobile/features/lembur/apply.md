# Mengajukan Lembur

{% tabs %}
{% tab title="Form Pengajuan" %}

### Cara Mengajukan Lembur Baru

1. Buka halaman **Lembur** (dari dashboard tap icon ⏰)
2. Tap tombol **Ajukan Lembur** (pojok kanan atas)
3. Isi **Form Pengajuan Lembur**:

![Form pengajuan lembur — tipe, tanggal, jam, dan alasan](https://placehold.co/600x1200/1a1a2e/ffffff?text=form-lembur)

### Detail Form

| Field | Wajib? | Keterangan |
|---|---|---|
| **Tipe Lembur** | ✅ Ya | Pilih: Lembur Hari Kerja atau Lembur Hari Libur |
| **Tanggal** | ✅ Ya | Tanggal lembur |
| **Jam Mulai** | ✅ Ya | Perkiraan jam mulai lembur |
| **Jam Selesai** | ✅ Ya | Perkiraan jam selesai lembur |
| **Durasi** | ✅ Ya | Terisi otomatis |
| **Alasan / Tugas** | ✅ Ya | Deskripsi pekerjaan yang dilakukan |

{% endtab %}
{% tab title="Tips Pengisian" %}

### Tips Pengisian

- Pastikan **jam mulai** dan **jam selesai** realistis
- Jelaskan **tugas** yang dikerjakan selama lembur dengan jelas
- Lembur hari kerja biasanya dihitung setelah jam kerja reguler selesai

{% hint style="warning" %}
Lembur harus **disetujui oleh atasan** terlebih dahulu sebelum dikerjakan. Jangan bekerja lembur tanpa approval yang sah.
{% endhint %}

{% endtab %}
{% tab title="Setelah Mengajukan" %}

### Setelah Mengajukan

1. Pengajuan masuk ke daftar **Pending**
2. Approver menerima notifikasi
3. Kamu mendapat notifikasi saat **disetujui** atau **ditolak**

{% endtab %}
