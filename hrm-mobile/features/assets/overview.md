# Overview Aset

Modul **Aset** (Assets) menampilkan data aset perusahaan yang sedang kamu pegang / gunakan, seperti laptop, HP, kendaraan, atau perlengkapan kantor lainnya.

## Status Aset

| Status | Arti |
|---|---|
| **Baik** (Good) | Aset dalam kondisi baik |
| **Terpakai** (Usable) | Aset berfungsi normal |
| **Rusak Ringan** (Light Damage) | Ada kerusakan minor |
| **Rusak Berat** (Heavy Damage) | Kerusakan signifikan |
| **Hilang** (Lost) | Aset hilang |

## Cara Melihat

1. Dari **Dashboard**, tap icon **💼 Aset**
2. Lihat daftar aset yang di-handover ke kamu

![Daftar Aset](.assets/images/hrm-mobile/assets/daftar-aset.png)

Setiap item menampilkan:
- **Nama Aset** (misal: Lenovo ThinkPad X1)
- **Kode Aset** / Serial Number
- **Status** (dengan badge warna)
- **Tanggal Handover**

## Detail Aset

Tap untuk melihat detail lengkap:

![Detail Aset](.assets/images/hrm-mobile/assets/detail-aset.png)

Detail meliputi:
- Nama & kode aset
- Spesifikasi (jika ada)
- Status terkini
- Riwayat handover (siapa saja yang pernah memegang)
