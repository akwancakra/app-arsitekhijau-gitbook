# Overview Aset

Modul **Aset** (Assets) menampilkan data aset perusahaan yang sedang kamu pegang / gunakan, seperti laptop, HP, kendaraan, atau perlengkapan kantor lainnya.

{% hint style="warning" %}
**Laporkan Kerusakan Segera!** — Jika aset yang kamu pegang mengalami kerusakan, segera laporkan ke HR atau tim terkait untuk mendapatkan penanganan lebih lanjut.
{% endhint %}

## Status Aset

{% tabs %}
{% tab title="✅ Baik" %}
{% hint style="success" %}
**Baik (Good)** — Aset dalam kondisi baik dan berfungsi normal tanpa kendala.
{% endhint %}
{% endtab %}

{% tab title="🔧 Terpakai" %}
{% hint style="info" %}
**Terpakai (Usable)** — Aset berfungsi normal, sedang dalam pemakaian aktif.
{% endhint %}
{% endtab %}

{% tab title="⚠️ Rusak Ringan" %}
{% hint style="warning" %}
**Rusak Ringan (Light Damage)** — Ada kerusakan minor. Segera koordinasikan dengan HR untuk perbaikan.
{% endhint %}
{% endtab %}

{% tab title="🚨 Rusak Berat" %}
{% hint style="danger" %}
**Rusak Berat (Heavy Damage)** — Kerusakan signifikan. Aset perlu perbaikan atau penggantian.
{% endhint %}
{% endtab %}

{% tab title="❌ Hilang" %}
{% hint style="danger" %}
**Hilang (Lost)** — Aset dinyatakan hilang. Segera laporkan ke HR dan buat laporan kehilangan.
{% endhint %}
{% endtab %}
{% endtabs %}

## Cara Melihat

1. Dari **Dashboard**, tap icon **💼 Aset**
2. Lihat daftar aset yang di-handover ke kamu

![Daftar Aset](https://placehold.co/600x1200/1a1a2e/ffffff?text=daftar-aset)

Setiap item menampilkan:
- **Nama Aset** (misal: Lenovo ThinkPad X1)
- **Kode Aset** / Serial Number
- **Status** (dengan badge warna)
- **Tanggal Handover**

## Detail Aset

{% details title="📋 Informasi lengkap yang tersedia di detail aset" %}
Tap pada aset untuk melihat detail lengkap:

![Detail Aset](https://placehold.co/600x1200/1a1a2e/ffffff?text=detail-aset)

Detail meliputi:
- **Nama & Kode Aset** — Identifikasi lengkap aset
- **Spesifikasi** — Informasi teknis (jika ada)
- **Status Terkini** — Kondisi aset saat ini
- **Riwayat Handover** — Siapa saja yang pernah memegang aset ini sebelumnya
{% enddetails %}
