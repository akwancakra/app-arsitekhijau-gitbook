# Request & Approval

{% tabs %}
{% tab title="📝 Mengajukan" %}
## Mengajukan Perubahan Profil

![Pilih Section](https://placehold.co/600x400/1a1a2e/ffffff?text=pilih-section)

1. Buka halaman **Profile Change Request**
2. Pilih **section** data yang ingin diubah:
   - Personal Information
   - Family Detail
   - Emergency Contact
   - Education & Experience
   - Additional Info
   - Bank Information
3. Isi **data baru** yang benar
4. (Opsional) **Lampirkan dokumen pendukung** (foto KTP, KK, ijazah, dll)
5. Tulis **alasan perubahan** (wajib)
6. Tap **Kirim**

![Form Profile Change](https://placehold.co/600x400/1a1a2e/ffffff?text=form)

### Lampiran

{% hint style="info" %}
**Format File yang Didukung** — Kamu dapat melampirkan dokumen dalam format: **PDF, JPG, JPEG, PNG**. Maksimal ukuran file **5MB** per lampiran.
{% endhint %}
{% endtab %}

{% tab title="✅ Approval" %}
## Approval (untuk Approver)

1. Buka halaman **Profile Change Request**
2. Pilih tab **Approval**
3. Lihat daftar request yang perlu di-approve

![Daftar Approval](https://placehold.co/600x1200/1a1a2e/ffffff?text=daftar-approval)

### Setujui

1. Tap request untuk lihat detail
2. Periksa data lama vs data baru
3. Tap **Setujui**
4. (Opsional) Tambahkan catatan

{% hint style="success" %}
**Approved** — Permintaan disetujui. Data profil akan langsung terupdate di sistem.
{% endhint %}

### Tolak

1. Tap **Tolak**
2. Tulis alasan penolakan (wajib)
3. Konfirmasi

{% hint style="warning" %}
**Rejected** — Permintaan ditolak. Data profil tidak berubah. Kamu bisa mengajukan ulang setelah memperbaiki alasan atau data.
{% endhint %}
{% endtab %}
{% endtabs %}

## Status

| Status | Arti |
|---|---|
| **Pending** | Menunggu approval |
| **Approved** | Disetujui — data profil sudah diperbarui |
| **Rejected** | Ditolak — data tidak berubah |

> **Catatan:** Setelah disetujui, data profil akan langsung terupdate di sistem.
