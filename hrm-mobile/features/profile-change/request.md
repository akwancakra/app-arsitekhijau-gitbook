# Request & Approval

## Mengajukan Perubahan Profil

![Pilih Section](.assets/images/hrm-mobile/profile-change/pilih-section.png)

1. Buka halaman **Profile Change Request**
2. Pilih **section** data yang ingin diubah:
   - Personal Information
   - Family Detail
   - Emergency Contact
   - Education & Experience
   - Additional Info
   - Bank Information
3. Isi **data baru** yang benar
4. (Opsional) **Lampirkan dokumen pendukung** (foto KTP, KK, ijazah, dll)
5. Tulis **alasan perubahan** (wajib)
6. Tap **Kirim**

![Form Profile Change](.assets/images/hrm-mobile/profile-change/form.png)

## Approval (untuk Approver)

1. Buka halaman **Profile Change Request**
2. Pilih tab **Approval**
3. Lihat daftar request yang perlu di-approve

![Daftar Approval](.assets/images/hrm-mobile/profile-change/daftar-approval.png)

**Setujui:**
1. Tap request untuk lihat detail
2. Periksa data lama vs data baru
3. Tap **Setujui**
4. (Opsional) Tambahkan catatan

**Tolak:**
1. Tap **Tolak**
2. Tulis alasan penolakan (wajib)
3. Konfirmasi

## Status

| Status | Arti |
|---|---|
| **Pending** | Menunggu approval |
| **Approved** | Disetujui — data profil sudah diperbarui |
| **Rejected** | Ditolak — data tidak berubah |

> **Catatan:** Setelah disetujui, data profil akan langsung terupdate di sistem.
