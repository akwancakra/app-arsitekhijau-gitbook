# Riwayat Absensi

Riwayat Absensi menampilkan **daftar record kehadiran** kamu setiap hari. Kamu bisa melihat status, jam masuk, jam pulang, dan detail lainnya.

## Cara Melihat Riwayat Absensi

![Daftar riwayat absensi per hari dengan status dan jam](https://placehold.co/600x1200/1a1a2e/ffffff?text=riwayat-list)

1. Dari **Dashboard Home**, tap card **Absensi** atau icon **📋 Absensi**
2. Atau dari halaman **Absensi**, scroll ke bawah ke section **Riwayat**
3. Riwayat ditampilkan dalam bentuk list per hari (terbaru di atas)

{% hint style="info" %}
Riwayat menggunakan **infinite scroll** — data akan terus dimuat saat kamu scroll ke bawah. Tarik layar ke bawah (**pull-to-refresh**) untuk memuat ulang data terbaru.
{% endhint %}

## Informasi di Setiap Record

Setiap item riwayat menampilkan:

| Informasi | Contoh |
|---|---|
| **Tanggal** | Senin, 12 Juni 2026 |
| **Status** | Hadir ✅ / Terlambat 🔴 / Izin 🟢 |
| **Jam Masuk** | 08:00 WIB |
| **Jam Pulang** | 17:30 WIB |
| **Durasi** | 9j 30m |
| **Keterangan** | (opsional, jika ada catatan) |

## Detail Record Absensi

Tap pada salah satu record untuk melihat detail lengkap:

![Detail record absensi — informasi clock in dan clock out](https://placehold.co/600x1200/1a1a2e/ffffff?text=detail-record)

{% details title="Lihat Detail Record" %}
Detail meliputi:

- **Clock In**: waktu, lokasi (alamat + koordinat GPS), foto selfie
- **Clock Out**: waktu, lokasi, foto selfie
- **Durasi kerja** dalam jam dan menit
- **Status akhir** dan keterangan
- **Shift** yang dijalani
{% enddetails %}

## Filter & Pencarian

- Riwayat ditampilkan secara **infinite scroll** (muat lebih banyak saat scroll ke bawah)
- Urutan **terbaru di atas** (descending by date)
- Data bisa di-pull-to-refresh
