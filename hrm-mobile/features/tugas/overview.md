# Overview Tugas

Modul **Tugas** (Tasks) menampilkan daftar tugas yang perlu kamu kerjakan. Tugas bisa berasal dari atasan, project, atau pekerjaan rutin.

## Status Tugas

| Status | Arti |
|---|---|
| **Pending** | Tugas baru, belum dikerjakan |
| **In Progress** | Sedang dikerjakan |
| **In Review** | Selesai dikerjakan, menunggu review |
| **Done** | Selesai dan sudah direview |

## Fitur yang Tersedia

| Fitur | Deskripsi |
|---|---|
| **Daftar Tugas** | List tugas dengan infinite scroll |
| **Filter** | Filter berdasarkan status, project, prioritas |
| **Sort** | Urutkan berdasarkan tanggal / status / prioritas |
| **Detail Tugas** | Informasi lengkap per tugas |
