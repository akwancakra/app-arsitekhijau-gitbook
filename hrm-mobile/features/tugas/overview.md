# Overview Tugas

Modul **Tugas** (Tasks) menampilkan daftar tugas yang perlu kamu kerjakan. Tugas bisa berasal dari atasan, project, atau pekerjaan rutin.

## Status Tugas

{% tabs %}
{% tab title="📋 Pending" %}
{% hint style="info" %}
**Pending**: Tugas baru, belum dikerjakan. Segera tentukan prioritas dan mulai pengerjaan.
{% endhint %}
{% endtab %}

{% tab title="⚙️ In Progress" %}
{% hint style="warning" %}
**In Progress**: Sedang dikerjakan. Pastikan untuk mengikuti deadline yang ditentukan.
{% endhint %}
{% endtab %}

{% tab title="🔍 In Review" %}
{% hint style="info" %}
**In Review**: Selesai dikerjakan, menunggu review dari atasan atau project manager.
{% endhint %}
{% endtab %}

{% tab title="✅ Done" %}
{% hint style="success" %}
**Done**: Selesai dan sudah direview. Tugas telah disetujui.
{% endhint %}
{% endtab %}
{% endtabs %}

## Fitur yang Tersedia

| Fitur | Deskripsi |
|---|---|
| **Daftar Tugas** | List tugas dengan infinite scroll |
| **Filter** | Filter berdasarkan status, project, prioritas |
| **Sort** | Urutkan berdasarkan tanggal / status / prioritas |
| **Detail Tugas** | Informasi lengkap per tugas |
