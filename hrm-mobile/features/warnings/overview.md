# Overview Peringatan

Modul **Peringatan** (Warnings) menampilkan surat peringatan yang dikeluarkan oleh HR / Manajemen. Jika ada pelanggaran atau masalah kedisiplinan, surat peringatan akan muncul di sini.

## Yang Ditampilkan

| Informasi | Keterangan |
|---|---|
| **Judul SP** | Jenis / nomor surat peringatan |
| **Tanggal** | Tanggal diterbitkan |
| **Status** | Aktif / Selesai |
| **Isi** | Detail pelanggaran dan tindakan |

## Cara Melihat

1. Dari **Dashboard**, tap icon **⚠️ Peringatan**
2. Lihat daftar surat peringatan (jika ada)

![Daftar Peringatan](.assets/images/hrm-mobile/warnings/daftar-peringatan.png)

3. Tap salah satu untuk melihat detail lengkap (rich HTML content)

![Detail Peringatan](.assets/images/hrm-mobile/warnings/detail-peringatan.png)

> **Catatan:** Jika tidak ada surat peringatan, halaman akan menampilkan status kosong.
