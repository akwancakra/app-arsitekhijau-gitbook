# Overview Pengumuman

Modul **Pengumuman** (Announcements) menampilkan informasi resmi dari HR / Manajemen perusahaan.

## Cara Melihat Pengumuman

1. Dari **Dashboard**, tap icon **📢 Pengumuman**
2. Lihat daftar pengumuman (terbaru di atas)

![Daftar Pengumuman](https://placehold.co/600x1200/1a1a2e/ffffff?text=daftar-pengumuman)

### Unread Indicator

{% hint style="success" %}
**🆕 NEW**: Pengumuman yang **belum dibaca** ditandai dengan badge **"NEW"** yang mencolok. Jumlah pengumuman belum dibaca juga terlihat di Dashboard.
{% endhint %}

## Detail Pengumuman

Tap untuk membaca isi lengkap:

![Detail Pengumuman](https://placehold.co/600x1200/1a1a2e/ffffff?text=detail-pengumuman)

- Konten dalam format rich text / HTML
- Tanggal dan waktu penerbitan

## Mark as Read

{% details title="📌 Bagaimana cara kerja Mark as Read?" %}
- **Otomatis**: Pengumuman langsung ditandai **sudah dibaca** saat kamu membuka halaman detailnya
- **Manual Massal**: Tap tombol **"Tandai Semua Sudah Dibaca"** (Mark All as Read) di bagian atas untuk menandai semua pengumuman sebagai sudah dibaca sekaligus
- **Sinkronasi**: Status baca akan tersimpan dan tersinkronasi di perangkat kamu
{% enddetails %}

{% hint style="info" %}
**Riwayat Dibaca**: Pengumuman yang sudah dibaca tetap tersimpan dalam riwayat. Kamu bisa membukanya kembali kapan saja.
{% endhint %}
