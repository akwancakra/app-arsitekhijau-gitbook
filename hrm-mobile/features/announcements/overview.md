# Overview Pengumuman

Modul **Pengumuman** (Announcements) menampilkan informasi resmi dari HR / Manajemen perusahaan.

## Cara Melihat Pengumuman

1. Dari **Dashboard**, tap icon **📢 Pengumuman**
2. Lihat daftar pengumuman (terbaru di atas)

![Daftar Pengumuman](.assets/images/hrm-mobile/announcements/daftar-pengumuman.png)

### Unread Indicator
- Pengumuman yang **belum dibaca** memiliki badge **"NEW"**
- Jumlah pengumuman belum dibaca terlihat di dashboard

## Detail Pengumuman

Tap untuk membaca isi lengkap:

![Detail Pengumuman](.assets/images/hrm-mobile/announcements/detail-pengumuman.png)

- Konten dalam format rich text / HTML
- Tanggal dan waktu penerbitan

## Mark as Read

- Pengumuman otomatis ditandai **sudah dibaca** saat kamu membukanya
- Tap **Tandai Semua Sudah Dibaca** (Mark All as Read) di bagian atas untuk menandai semua
