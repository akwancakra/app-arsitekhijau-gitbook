# Overview Organisasi

Modul **Organisasi** (Hierarchy / Employee Directory) memungkinkan kamu mencari dan melihat informasi rekan kerja serta struktur pelaporan di perusahaan.

## Fitur yang Tersedia

| Fitur | Deskripsi |
|---|---|
| **Pencarian** | Cari karyawan berdasarkan nama atau NIP |
| **Filter Cabang** | Filter berdasarkan branch / kantor cabang |
| **Infinite Scroll** | Scroll untuk memuat lebih banyak |
| **Detail Karyawan** | Informasi lengkap, atasan, dan tim |

## Cara Menggunakan

1. Dari **Dashboard**, tap icon **👥 Organisasi**
2. Lihat daftar karyawan:

![Direktori Karyawan](.assets/images/hrm-mobile/hierarchy/daftar-karyawan.png)

### Pencarian
1. Tap **search bar** di bagian atas
2. Ketik **nama** atau **NIP** karyawan
3. Hasil akan terfilter secara real-time

### Filter Cabang
1. Tap **Filter Cabang**
2. Pilih cabang / branch
3. Daftar akan difilter berdasarkan cabang

## Detail Karyawan

Tap pada nama karyawan untuk melihat detail:

![Detail Karyawan](.assets/images/hrm-mobile/hierarchy/detail-karyawan.png)

Detail menampilkan:
- **Foto & Nama**
- **NIP / Employee ID**
- **Jabatan / Posisi**
- **Branch / Cabang**
- **Reports To** (atasan langsung)
- **Team Members** (anggota tim)
- **Kontak** (email, telepon)
