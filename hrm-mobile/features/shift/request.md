# Request & Approval Shift

{% tabs %}
{% tab title="Mengajukan" %}

## Mengajukan Perubahan Shift

![Form request perubahan shift dengan field tanggal dan shift baru](https://placehold.co/600x1200/1a1a2e/ffffff?text=form-request)

1. Buka halaman **Shift** (dari dashboard tap icon 🔄)
2. Tap **Ajukan Perubahan Shift**
3. Isi form:

| Field | Wajib? | Keterangan |
|---|---|---|
| **Tanggal** | ✅ Ya | Tanggal shift yang ingin diubah |
| **Shift Saat Ini** | ✅ Ya | Shift yang terjadwal sekarang |
| **Shift Baru** | ✅ Ya | Shift pengganti yang diinginkan |
| **Alasan** | ✅ Ya | Alasan perubahan shift |

4. Tap **Kirim**

{% endtab %}
{% tab title="Approval" %}

## Approval Shift (untuk Approver)

1. Buka halaman **Shift**
2. Pilih tab **Approval**
3. Lihat daftar request shift yang perlu di-approve

![Daftar approval perubahan shift yang menunggu keputusan](https://placehold.co/600x400/1a1a2e/ffffff?text=approval)

{% hint style="info" %}
Sebagai approver, pastikan kamu memeriksa alasan perubahan shift dan ketersediaan jadwal sebelum menyetujui atau menolak.
{% endhint %}

**Setujui** → Tap **Setujui** + konfirmasi
**Tolak** → Tap **Tolak** + isi alasan + konfirmasi

{% endtab %}
{% endtabs %}

## Status

{% table data-view="cards" %}
| Status | Arti |
| --- | --- |
| **Pending** ⏳ | Permintaan menunggu approval atasan |
| **Approved** ✅ | Shift berhasil diubah sesuai permintaan |
| **Rejected** ❌ | Permintaan ditolak: shift tetap sesuai jadwal awal |
{% /table %}
