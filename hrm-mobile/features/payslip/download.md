# Melihat & Download Slip Gaji

## Melihat Slip Gaji

1. Dari **Dashboard**, tap icon **📄 Slip Gaji**
2. Lihat daftar slip gaji per bulan:

![Daftar Slip Gaji](.assets/images/hrm-mobile/payslip/daftar-payslip.png)

### Filter Tahun
1. Tap **Filter Tahun** di bagian atas
2. Pilih tahun yang diinginkan (atau "Semua")
3. Daftar akan difilter

## Detail Slip Gaji

Tap pada salah satu slip untuk melihat rincian:

![Detail Slip Gaji](.assets/images/hrm-mobile/payslip/detail-payslip.png)

Detail menampilkan:
- **Pendapatan**: gaji pokok, tunjangan tetap, tunjangan tidak tetap, lembur, bonus
- **Potongan**: BPJS Kesehatan, BPJS Ketenagakerjaan, PPh 21, pinjaman, potongan lain
- **Total Take Home Pay**: jumlah yang diterima

## Download PDF

1. Pada halaman detail slip, tap icon **Download** (pojok kanan atas)
2. Slip gaji akan di-download sebagai file PDF
3. File bisa dibuka atau dibagikan

![Download Slip Gaji](.assets/images/hrm-mobile/payslip/download-payslip.png)

> **Catatan:** File PDF tersimpan di perangkat kamu. Bisa dibuka kapan saja tanpa perlu koneksi internet.
