# Melihat & Download Slip Gaji

{% tabs %}
{% tab title="👁️ Lihat Detail" %}
## Melihat Slip Gaji

1. Dari **Dashboard**, tap icon **📄 Slip Gaji**
2. Lihat daftar slip gaji per bulan:

![Daftar Slip Gaji](https://placehold.co/600x1200/1a1a2e/ffffff?text=daftar-payslip)

## Detail Slip Gaji

Tap pada salah satu slip untuk melihat rincian:

![Detail Slip Gaji](https://placehold.co/600x1200/1a1a2e/ffffff?text=detail-payslip)

Detail menampilkan:
- **Pendapatan**: gaji pokok, tunjangan tetap, tunjangan tidak tetap, lembur, bonus
- **Potongan**: BPJS Kesehatan, BPJS Ketenagakerjaan, PPh 21, pinjaman, potongan lain
- **Total Take Home Pay**: jumlah yang diterima

{% hint style="info" %}
Komponen gaji bisa berbeda setiap bulan tergantung kehadiran, lembur, dan kebijakan perusahaan.
{% endhint %}
{% endtab %}

{% tab title="📅 Filter Tahun" %}
1. Tap **Filter Tahun** di bagian atas
2. Pilih tahun yang diinginkan (atau "Semua")
3. Daftar akan difilter sesuai tahun yang dipilih

{% hint style="info" %}
Pilih "Semua" untuk melihat seluruh riwayat slip gaji dari tahun ke tahun.
{% endhint %}
{% endtab %}

{% tab title="⬇️ Download PDF" %}
1. Pada halaman detail slip, tap icon **Download** (pojok kanan atas)
2. Slip gaji akan di-download sebagai file PDF
3. File bisa dibuka atau dibagikan

![Download Slip Gaji](https://placehold.co/600x400/1a1a2e/ffffff?text=download-payslip)

{% hint style="success" %}
**Berhasil!** File PDF slip gaji sudah tersimpan di perangkat kamu.
{% endhint %}

{% hint style="warning" %}
**Penting:** File PDF hanya tersimpan secara lokal di perangkat kamu. Pastikan untuk melakukan backup jika diperlukan.
{% endhint %}
{% endtab %}
{% endtabs %}
