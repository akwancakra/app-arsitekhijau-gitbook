# FAQ / Troubleshooting

{% tabs %}
{% tab title="Login & Akun" %}

{% details title="Q: Lupa password, bagaimana?" %}
Tap **Lupa Password?** di halaman login. Masukkan email perusahaan, cek email untuk link reset.
{% enddetails %}

{% details title="Q: Gagal login terus muncul &quot;Email atau password salah&quot;" %}
Pastikan email menggunakan domain perusahaan (@arsitekhijau.com). Cek caps lock. Jika masih gagal, gunakan **Lupa Password** atau hubungi IT.
{% enddetails %}

{% details title="Q: Akun terkunci karena salah password berkali-kali" %}
Hubungi IT support untuk membuka kunci akun.
{% enddetails %}

{% endtab %}
{% tab title="Absensi" %}

{% details title="Q: Lupa clock in, bagaimana?" %}
Gunakan fitur **Koreksi Absensi** (Past Day Correction). Ajukan koreksi dengan alasan yang jelas.
{% enddetails %}

{% details title="Q: Lupa clock out, gaji dipotong?" %}
Segera ajukan **Koreksi Absensi** untuk past day correction. Selama belum dikoreksi, sistem akan menghitung durasi tidak lengkap.
{% enddetails %}

{% details title="Q: GPS error saat clock in" %}
Pastikan GPS HP aktif. Coba ke luar ruangan. Restart aplikasi. Jika masih error, gunakan koreksi absensi.
{% enddetails %}

{% details title="Q: Lokasi tidak terdeteksi / tidak sesuai" %}
Pastikan berada di area kantor yang terdaftar. Jika lokasi benar tapi masih error, hubungi IT.
{% enddetails %}

{% endtab %}
{% tab title="Cuti & Lembur" %}

{% details title="Q: Saldo cuti tidak muncul / tidak sesuai" %}
Saldo dikelola oleh HR. Hubungi HR department jika ada ketidaksesuaian.
{% enddetails %}

{% details title="Q: Pengajuan cuti ditolak, kenapa?" %}
Cek alasan penolakan dari approver. Biasanya karena alasan operasional atau kuota. Ajukan ulang jika perlu.
{% enddetails %}

{% details title="Q: Lembur belum di-approve setelah beberapa hari" %}
Hubungi atasan langsung kamu. Approver mungkin belum melihat notifikasi.
{% enddetails %}

{% endtab %}
{% tab title="Notifikasi" %}

{% details title="Q: Tidak mendapat notifikasi dari aplikasi" %}
Cek: 1) Izin notifikasi di pengaturan HP. 2) Notifikasi di pengaturan aplikasi sudah ON. 3) Mode Jangan Ganggu (DND) mungkin aktif.
{% enddetails %}

{% details title="Q: Notifikasi clock reminder tidak muncul" %}
Pastikan **Clock Reminder** sudah diaktifkan di Account Settings dan jam sudah diatur dengan benar.
{% enddetails %}

{% endtab %}
{% tab title="Teknis" %}

{% details title="Q: Aplikasi lambat / loading terus" %}
Cek koneksi internet. Tutup dan buka ulang aplikasi. Jika masih lambat, coba clear cache di pengaturan HP.
{% enddetails %}

{% details title="Q: Update OTA gagal" %}
Cek koneksi internet. Pastikan penyimpanan HP mencukupi. Coba buka dan tutup aplikasi, lalu cek update lagi.
{% enddetails %}

{% details title="Q: Aplikasi force close / crash" %}
1) Restart HP. 2) Update ke versi terbaru. 3) Jika masih crash, laporkan ke IT dengan screenshot dan detail HP.
{% enddetails %}

{% details title="Q: Bagaimana cara update aplikasi dari Play Store / App Store?" %}
Buka Play Store / App Store, cari "HRM Arsitek Hijau", tap **Update** jika tersedia.
{% enddetails %}

{% endtab %}
{% tab title="Keamanan" %}

{% details title="Q: HP hilang / dicuri, bagaimana?" %}
Segera laporkan ke IT untuk mereset sesi login dan memblokir akses akun kamu.
{% enddetails %}

{% details title="Q: Lupa PIN aplikasi" %}
Pada halaman lock screen, tap **Lupa PIN?** dan verifikasi dengan password akun.
{% enddetails %}

{% details title="Q: Biometric tidak berfungsi" %}
Pastikan fingerprint/FaceID HP sudah terdaftar di pengaturan HP. Restart aplikasi. Jika masih error, gunakan PIN sebagai alternatif.
{% enddetails %}

{% endtab %}
{% endtabs %}
