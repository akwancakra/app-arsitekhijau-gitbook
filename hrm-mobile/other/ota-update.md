# OTA Update

**OTA (Over-The-Air) Update** memungkinkan aplikasi menerima pembaruan fitur terbaru secara langsung tanpa perlu mengunjungi Play Store atau App Store.

## Cara Kerja

Ada dua mode update OTA:

{% tabs %}
{% tab title="Auto Update" %}

### 1. Auto Update (Otomatis)

Jika **Auto Update** diaktifkan di Pengaturan:
- Aplikasi akan **mengecek update** secara periodik
- Saat update tersedia, akan **di-download di background**
- Saat sudah siap, aplikasi akan **restart** dengan versi baru
- Proses **transparan**: kamu tidak perlu melakukan apa-apa

{% endtab %}
{% tab title="Manual Update" %}

### 2. Manual Update

1. Buka **Account** tab
2. Tap **Tentang Aplikasi** (About)
3. Jika ada update, akan muncul notifikasi / bottom sheet

![Manual Update OTA](https://placehold.co/600x400/1a1a2e/ffffff?text=ota-manual-update)

4. Tap **Download & Install**
5. Tunggu proses download selesai
6. Tap **Restart** untuk menggunakan versi baru

{% endtab %}
{% endtabs %}

## Mandatory APK Update

{% hint style="danger" %}
**Mandatory update bersifat WAJIB**: kamu harus meng-install-nya untuk bisa terus menggunakan aplikasi. Biasanya menyangkut perubahan versi major atau perbaikan keamanan kritis.
{% endhint %}

Jika ada update **wajib**, aplikasi akan menampilkan layar penuh:

1. Muncul **Mandatory Update Sheet**
2. Tap **Download Update**
3. Aplikasi akan **men-download APK** terbaru
4. Setelah selesai, buka file untuk instalasi manual

![Mandatory Update](https://placehold.co/600x1200/1a1a2e/ffffff?text=mandatory-update)

{% hint style="info" %}
Mandatory update memerlukan instalasi manual karena perubahan versi major. Pastikan mengizinkan instalasi dari sumber tidak dikenal jika diminta.
{% endhint %}

## Cek Versi

{% hint style="info" %}
1. Buka **Account → Tentang Aplikasi**
2. Lihat **Versi Aplikasi** saat ini
3. Jika ada update, akan terlihat di sini
{% endhint %}

## Mengatur Auto Update

{% hint style="warning" %}
Sebaiknya biarkan **Auto Update** tetap aktif agar selalu mendapatkan fitur dan perbaikan terbaru. Matikan hanya jika ada alasan khusus (misal: kuota terbatas).
{% endhint %}

1. Buka **Account → Pengaturan**
2. Cari **Auto Update OTA**
3. Aktifkan / nonaktifkan sesuai keinginan
