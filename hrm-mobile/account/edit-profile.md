# Edit Profile

Halaman **Edit Profile** memungkinkan kamu mengubah foto profil dan melihat data diri lengkap.

## Cara Edit Profile

1. Buka tab **Account** (icon orang di pojok kanan bawah)
2. Tap **Edit Profile** (icon pensil di samping foto profil)

![Edit Profile](https://placehold.co/600x400/1a1a2e/ffffff?text=edit-profile)

{% tabs %}
{% tab title="Foto Profil" %}

### Mengganti Foto Profil

1. Tap foto profil saat ini
2. Pilih sumber foto:
   - **Kamera** — ambil foto baru
   - **Galeri** — pilih dari gallery HP
3. Atur posisi foto (crop & zoom)
4. Tap **Simpan**

{% endtab %}
{% tab title="Data Pribadi" %}

### Data yang Bisa Diubah

- **Nama lengkap** (jika diizinkan HR)
- **Nomor telepon**
- **Email** (beberapa kasus perlu approval HR)

{% hint style="info" %}
Perubahan data tertentu seperti alamat, status pernikahan, atau data keluarga membutuhkan **Profile Change Request** yang akan di-approve oleh HR.
{% endhint %}

{% endtabs %}

## Informasi Pribadi

Dari halaman **Account**, kamu bisa melihat info pribadi lengkap:

| Menu | Data |
|---|---|
| **Personal Information** | Nama, NIP, tempat/tanggal lahir, jenis kelamin |
| **Job Information** | Jabatan, departemen, branch, atasan |
| **Payroll Details** | Gaji pokok, tunjangan, BPJS, NPWP |
| **Family Details** | Status pernikahan, data pasangan & anak |
| **Emergency Contacts** | Kontak darurat |
| **Education & Experience** | Riwayat pendidikan & pengalaman kerja |
| **Additional Info** | Informasi tambahan |

Tap masing-masing menu untuk melihat detail (data bersifat **read-only** kecuali diubah via Profile Change Request).
