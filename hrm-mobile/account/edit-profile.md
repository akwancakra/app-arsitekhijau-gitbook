# Edit Profile

Halaman **Edit Profile** memungkinkan kamu mengubah foto profil dan melihat data diri lengkap.

## Cara Edit Profile

1. Buka tab **Account** (icon orang di pojok kanan bawah)
2. Tap **Edit Profile** (icon pensil di samping foto profil)

![Edit Profile](https://placehold.co/600x400/1a1a2e/ffffff?text=edit-profile)

---

### Foto Profil

**Mengganti Foto Profil**

1. Tap foto profil saat ini
2. Pilih sumber foto:
   - **Kamera**: ambil foto baru langsung dari kamera
   - **Galeri**: pilih foto yang sudah ada di gallery HP
3. Atur posisi foto (crop & zoom) sesuai keinginan
4. Tap **Simpan** untuk menyimpan perubahan

{% hint style="info" %}
Foto profil akan langsung terupdate di seluruh sistem: dashboard, profile, dan direktori karyawan.
{% endhint %}

---

### Data Pribadi

**Data yang Bisa Diubah Langsung**

| Data | Keterangan |
|---|---|
| **Nama lengkap** | Hanya jika diizinkan oleh HR |
| **Nomor telepon** | Nomor HP yang aktif |
| **Email** | Beberapa perubahan perlu approval HR |

**Data yang Perlu Profile Change Request**

Jika ingin mengubah data berikut, gunakan **Profile Change Request** (butuh approval HR/atasan):

- Alamat tempat tinggal
- Status pernikahan
- Data keluarga (pasangan, anak)
- Kontak darurat
- Riwayat pendidikan & pengalaman kerja
- Data rekening bank
- Dokumen pribadi (KTP, NPWP, KK)

{% hint style="info" %}
Semua perubahan via Profile Change Request akan melalui proses approval sebelum data benar-benar berubah.
{% endhint %}

---

## Informasi Pribadi

Dari halaman **Account**, kamu bisa melihat info pribadi lengkap (read-only) dengan mengetuk menu-menu berikut:

| Menu | Data |
|---|---|
| Personal Information | Nama, NIP, tempat/tanggal lahir, jenis kelamin |
| Job Information | Jabatan, departemen, branch, atasan |
| Payroll Details | Gaji pokok, tunjangan, BPJS, NPWP |
| Family Details | Status pernikahan, data pasangan & anak |
| Emergency Contacts | Kontak darurat |
| Education & Experience | Riwayat pendidikan & pengalaman kerja |
| Additional Info | Informasi tambahan |
