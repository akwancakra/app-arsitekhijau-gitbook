# PIN Lock & Biometric

Fitur keamanan tambahan untuk melindungi akses ke aplikasi HRM Mobile kamu.

{% tabs %}
{% tab title="PIN Lock" %}

PIN adalah kode **6-digit** yang diminta setiap kali membuka aplikasi (setelah login).

{% tabs %}
{% tab title="Aktifkan" %}

### Cara Mengaktifkan PIN

1. Buka tab **Account**
2. Tap **PIN Settings**
3. Tap **Aktifkan PIN**

![Setup PIN](https://placehold.co/600x400/1a1a2e/ffffff?text=setup-pin)

4. Masukkan **PIN 6-digit** baru
5. Masukkan **ulang PIN** untuk konfirmasi
6. PIN aktif

{% endtab %}
{% tab title="Ubah" %}

### Cara Mengganti PIN

1. Buka **Account → PIN Settings**
2. Tap **Ubah PIN**
3. Masukkan **PIN lama**
4. Masukkan **PIN baru** (6 digit)
5. Konfirmasi PIN baru

{% endtab %}
{% tab title="Lupa" %}

### Melupakan PIN

{% hint style="warning" %}
Jika lupa PIN, kamu harus verifikasi dengan **password akun** sebelum bisa membuat PIN baru.
{% endhint %}

1. Tap **Lupa PIN?** di halaman lock screen
2. Masukkan **password akun** untuk verifikasi
3. Buat PIN baru
4. Selesai

{% endtab %}
{% tab title="Nonaktifkan" %}

### Menonaktifkan PIN

1. Buka **Account → PIN Settings**
2. Tap **Nonaktifkan PIN**
3. Masukkan PIN saat ini
4. PIN dinonaktifkan

{% endtab %}
{% endtabs %}

{% hint style="danger" %}
**Jangan bagikan PIN ke siapapun!** PIN bersifat rahasia dan hanya kamu yang boleh mengetahuinya.
{% endhint %}

{% endtab %}
{% tab title="Biometric" %}

## Biometric Unlock

{% hint style="info" %}
**Cara Kerja:** Setelah diaktifkan, kamu bisa membuka aplikasi cukup dengan **scan fingerprint** atau **FaceID** — tanpa perlu memasukkan PIN setiap kali. PIN tetap diperlukan sebagai cadangan jika biometric gagal.
{% endhint %}

Fitur ini mendukung:
- **Fingerprint** — untuk HP dengan sensor sidik jari
- **FaceID** — untuk HP dengan face recognition

### Cara Mengaktifkan

1. Buka **Account → PIN Settings**
2. Pastikan **PIN sudah aktif**
3. Tap **Aktifkan Biometric**
4. Ikuti verifikasi biometric HP
5. Biometric aktif

### Cara Kerja

- Buka aplikasi → muncul lock screen
- **Scan fingerprint** atau **FaceID**
- Langsung masuk (tanpa perlu PIN)

{% hint style="info" %}
Biometric hanya sebagai alternatif. PIN tetap diperlukan sebagai cadangan.
{% endhint %}
