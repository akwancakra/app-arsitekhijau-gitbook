# Welcome

Selamat datang di **HRM Mobile Arsitek Hijau** — aplikasi mobile HR terpadu untuk seluruh karyawan Arsitek Hijau.

Dokumentasi ini berisi panduan lengkap cara penggunaan setiap fitur yang tersedia, mulai dari instalasi, absensi, pengajuan cuti, lembur, hingga pengaturan akun pribadi.

## Fitur yang Tersedia

| Modul | Deskripsi |
|---|---|
| **Absensi** | Clock In/Out dengan GPS & selfie, riwayat, koreksi absensi |
| **Cuti** | Saldo cuti, pengajuan, approval leave request |
| **Lembur** | Pengajuan lembur kerja & hari libur |
| **Perubahan Shift** | Request perubahan jadwal shift |
| **Tugas** | List tugas, filter status, detail tugas |
| **Slip Gaji** | Lihat & download slip gaji bulanan |
| **Peringatan** | Surat peringatan dari HR |
| **SOP** | Dokumen SOP perusahaan |
| **Pengumuman** | Pengumuman internal dari management |
| **Aset** | Data aset perusahaan yang di-handover |
| **Kalendar** | Hari libur, jadwal kerja, cuti bersama |
| **Organisasi** | Direktori karyawan & struktur organisasi |
| **Profile Change** | Request perubahan data profil |
| **Notifikasi** | Push notification & inbox |
